
# Dynamic Shopping Cart 🛒

A responsive, interactive shopping cart web application. Users can browse products, add or remove items, adjust quantities dynamically, and view real-time price calculations for subtotals and grand totals.

## 🚀 Features

* **Dynamic Item Management:** Add, remove, and update quantities of items without page reloads.
* **Real-Time Calculations:** Automatic instant updates to subtotals, taxes, and final totals upon state changes.
* **State Persistence:** Preserves shopping cart contents across browser refreshes using `localStorage`.
* **Responsive Layout:** Clean design optimized across mobile, tablet, and desktop screens.

## 🛠️ Tech Stack

* **HTML5:** Semantic document structure.
* **CSS3:** Custom styles using modern layout techniques (Flexbox / Grid).
* **JavaScript:** DOM manipulation, event handling, and functional array methods (`map`, `filter`, `reduce`).
